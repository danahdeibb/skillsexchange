# Skills Exchange

## Description
Skills Exchange is a community-driven web platform where users can swap skills for free. Built with ReactJS as a Phase 2 upgrade from a plain HTML/CSS project.

## Live Demo
https://skillsexchange-tau.vercel.app

## Pages
- **Home** – Hero section with call to action
- **About Us** – Community impact table
- **Browse Skills** – Skills card gallery
- **Join Us** – Registration form

## Technologies Used
- ReactJS
- React Router DOM v6
- Bootstrap 5
- CSS3

## Setup Instructions
1. Clone the repository: `git clone https://github.com/12430287-ctrl/skillsexchange.git`
2. Install dependencies: `npm install`
3. Run locally: `npm start`
